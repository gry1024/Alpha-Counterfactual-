# 初始 50 因子池：方案比较

最终采用 `quality`：Alpha158 10 + AlphaSAGE 16 + AlphaPROBE 18 + AlphaGen 6。四种来源均缩减，50 个公式和 50 个规范化骨架均唯一，覆盖 14 类 OHLCV 经济结构，每类最多 6 个。

## 比较协议

- 候选来自本地 Qlib 的 30 个 Alpha158 字段及 README 中列出的三个现有搜索池（50/50/20）。原 start_pool 中的 AlphaPROBE 列表与指定来源池当前内容不同，本次直接以指定来源文件为准，保存来源索引和哈希。
- 150 个候选均重新评价；144 个通过合法性、可观测变化和相对可交易股票的 ≥80% Train 覆盖检查。来源的旧权重和旧评分不参与选池。
- 2015–2021 用于单因子 |RankIC| 和日均绝对 Spearman；删除 20 日标签跨越 Train 末端的样本。经济结构按可观察 OHLCV 运算标注，不声称覆盖估值、盈利、宏观等数据未提供的结构。
- 骨架去掉常量、窗口和外层缩放，规范化 Add/Mul/Min/Max/Corr/Cov 的交换顺序，每个骨架只留一个。覆盖尚未出现的结构优先；同一优先级最大化 |RankIC| − penalty × 已选成员最大相关性。每类最多 6 个，来源数量严格匹配方案配额。
- 先达到最大结构覆盖，再要求平均日均绝对相关性 ≤0.20 和各方案两两相关上限；在合格方案中以 2022 Sharpe 择优，累计收益破同分。此处多样性是准入约束，非收益的附带奖励。
- 所有曲线都仅使用冻结初始 50 个成员；逐日扩展历史、带符号的 rank OLS。预测日 t 的回归仅用行 ≤t−20−1 的已成熟标签，不使用当日或未来标签；所有方案使用同一口径。
- 选择截面预测最高的 20% 可交易股票，计算 close→next close 的多头毛收益，逐日复利，包含首日收益。日期为产生预测的交易日：2021-01-04–2021-12-31（243 天），2022-01-04–2022-12-29（241 天）；最后收益实现至 2022-12-30。CSI300 用同日对齐的下一交易日 pctchg。
- 2021 曲线属于诊断（候选质量估计也用了该年），2022 已用于方案选择，不属于未见样本。没有读取 2023.05.01–2026.04.30 Test，没有运行整个训练或 LLM。与最终公共回测的 z-score、自适应因子筛选口径不同；未计交易成本。

## 复现与产物

```bash
source .venv/bin/activate
OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4 python plot_profit_curve_start_pool.py --write-pool
python -m unittest discover -s tests -v
```

`profit_curve_start_pool.png` 为可审阅的曲线（脚本源文件 `plot_profit_curve_start_pool.py` 当前不在工作区，仅余 `__pycache__/*.pyc`，需从历史 commit 恢复或重写）；完整方案、公式、指标、来源路径/哈希在 `data/cf_logs/start_pool_comparison/comparison.json`。同目录保存各方案池、daily_returns.csv、candidates.json、correlations.npy 及 initialization_check.json；数据产物沿用仓库 data/ 忽略规则。

真实 Train 初始化已单独验证：50 个成员全部可评价，数量/顺序不变，不触发演化或最终 Test。数值测试覆盖直接加载、错误大小/重复/无效种子、交换律/常量/窗口去重、历史标签隔离与复利首日/回撤；保留原有反事实机制的合成信号回归测试。

训练中的初始筛选函数和相关消融开关已删除；start_pool.json 即 P₀。
